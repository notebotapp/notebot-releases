# Notebot — installers

This repository only holds the built installers for **Notebot**, the study-notes
app. The source lives in a private repository.

## Install on a Mac (Apple Silicon)

1. Open **Releases** on the right and download the newest `Notebot-x.y.z.dmg`.
2. Open the image, drag **Notebot** into **Applications**.
3. The first time, macOS says it cannot verify the app (it is not from the App
   Store). Close the message, open **System Settings → Privacy & Security**,
   scroll down and press **Open Anyway**. Only needed once.
4. Notebot asks your name, a folder for your notes and your free Gemini key
   (the app has a button that takes you to Google AI Studio to create one).

Once installed, Notebot checks here for new versions once a day and offers to
update itself.
